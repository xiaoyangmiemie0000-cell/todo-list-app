# 📝 待办事项应用

一个功能完整的待办事项管理应用，支持本地存储、实时数据同步和多项高级功能。

## ✨ 功能特性

### 核心功能
- ✅ **添加待办事项** - 快速输入新的任务
- ✅ **标记完成** - 点击复选框标记任务完成
- ✅ **删除任务** - 移除单个待办事项
- ✅ **本地存储** - 自动保存到浏览器本地存储
- ✅ **数据持久化** - 关闭浏览器数据不丢失

### 高级功能
- 🔍 **智能筛选** - 全部/进行中/已完成三种视图
- 📊 **实时统计** - 显示总数、已完成、进行中的任务数
- 🎨 **现代UI设计** - 响应式设计，支持所有设备
- 🌈 **优先级标签** - 高/中/低三个优先级
- 🗑️ **批量清空** - 快速删除所有已完成的项目
- ⌨️ **键盘快捷键** - 支持Enter键快速添加
- 🛡️ **XSS防护** - HTML转义保护用户数据

## 📖 使用指南

### 基础操作
1. **添加任务**
   - 在输入框中输入任务描述
   - 点击"添加"按钮或按Enter键

2. **标记完成**
   - 点击任务左侧的复选框
   - 已完成的任务会显示为灰色并带有删除线

3. **删除任务**
   - 点击任务右侧的"删除"按钮
   - 任务会立即从列表中移除

4. **筛选任务**
   - 点击"全部"、"进行中"或"已完成"按钮
   - 列表会自动过滤显示相应的任务

5. **清空已完成任务**
   - 点击底部"清空已完成的项目"按钮
   - 系统会要求确认后删除所有已完成的任务

## 💾 数据存储

### 本地存储工作原理
- 数据使用浏览器的 `localStorage` API 存储
- 存储键名：`todos`
- 数据格式：JSON
- 存储位置：浏览器本地，同域名、同浏览器访问可读取

### 查看存储数据
在浏览器控制台执行：
```javascript
// 查看所有待办事项
console.log(JSON.parse(localStorage.getItem('todos')))

// 手动导出数据
const data = localStorage.getItem('todos');
copy(data);  // 复制到剪贴板

// 手动清除所有数据
localStorage.removeItem('todos');
```

## 🐛 常见问题

**Q: 数据存储在哪里？**
A: 数据存储在浏览器的 localStorage 中，每个浏览器和域名都有独立的存储空间。

**Q: 数据会丢失吗？**
A: 不会。数据会一直保存在浏览器中，除非手动清除浏览器数据或调用 `localStorage.clear()`。

**Q: 能否在不同设备间同步？**
A: 目前不支持。如需跨设备同步，可以修改代码使用云服务（如Firebase）。

**Q: 如何导出我的数据？**
A: 在浏览器控制台执行 `exportTodos()` 函数即可导出为JSON文件。

**Q: 支持离线使用吗？**
A: 完全支持！这是一个纯前端应用，无需网络连接。
